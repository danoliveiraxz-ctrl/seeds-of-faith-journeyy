# Sementes de Fé para Famílias

Quero que você REESTRUTURE E OTIMIZE a landing page existente do produto “Sementes de Fé”.

IMPORTANTE:

Não crie uma página completamente diferente e genérica.

Analise a estrutura, conteúdo e identidade visual já existentes e faça uma evolução profissional focada em CONVERSÃO, VSL e confiança.

O produto é um material cristão infantil digital para famílias.

Nome:

Sementes de Fé

2. POSICIONAMENTO

==================================================

O conceito central da página deve ser:

“Transformar pequenos momentos do dia em oportunidades para conversar com as crianças sobre Deus, Jesus, oração e valores cristãos.”

Não vender como:

- método milagroso;

- solução para comportamento infantil;

- garantia de que a criança terá fé;

- substituto da educação dos pais;

- ferramenta de salvação;

- obrigação religiosa.

A comunicação deve ser emocional, mas ética.

Não usar culpa religiosa.

Não usar frases como:

“Se você ama seu filho, precisa comprar.”

“Deus quer que você compre.”

“Seu filho vai perder a fé se você não fizer isso.”

“Pais de verdade fazem isso.”
